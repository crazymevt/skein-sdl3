# skein-sdl3

[SDL3](https://libsdl.org/) bindings for [Skein](https://github.com/crazymevt/skein): the
functions, structs, enums and constants of SDL's init, error, hints, timer, rect, pixels,
blend mode, surface, video, render, events, keyboard, keycode, scancode and mouse headers,
as the namespace `sdl3.raw`. They are generated by `skein bindgen`; don't edit them by hand.

## Using it

Add it to your project's `project.skn`:

```clojure
{:name "game"
 :main game.main/-main
 :deps {skein/sdl3 {:git "https://github.com/crazymevt/skein-sdl3" :tag "v0.2.0"}}}
```

and require it:

```clojure
(ns game.main
  (:require [sdl3.raw :as sdl]))
```

`skein build`, `run`, `dev` and `package` fetch it (with `git`) into Skein's dependency
cache, and `skein.lock` records the commit.

SDL3 itself is a C library you install (on macOS: `brew install sdl3`) or ship with your
game: list it in your project's `:native` libraries and `skein package` puts it in the
package.

```clojure
 :native {:libs {:macos ["vendor/macos/libSDL3.dylib"]
                 :linux ["vendor/linux/libSDL3.so.0"]
                 :windows ["vendor/windows/SDL3.dll"]}}
```

Variadic functions (`SDL_SetError`, `SDL_RenderDebugTextFormat`) are bound with their
fixed parameters only, so `(sdl/set-error "message")` works. To pass more arguments,
declare a shape of your own, as `skein.ffi` describes:

```clojure
(ffi/defcfun set-error-int "SDL_SetError" bool [fmt c-string & n i32])
```

## Regenerating the bindings

With clang, the SDL3 headers and a Skein checkout next to this one:

```sh
make bindings SKEIN=../skein SDL3_INCLUDE=/opt/homebrew/include
```

The Makefile lists the headers bound and the functions marked blocking (they may wait,
so a fiber calling them lets others run).
